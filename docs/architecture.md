# Architecture

Where things live, and the one contract each module holds its callers to.

The *reasoning* behind each shape — which bug it prevents, which alternative was tried
and why it failed — lives in that module's own header comment, next to the code it
constrains. Read the bullet to find the file; read the file's header before changing it.

## Code Map

- `src/App.tsx`: React orchestration, draft/import state, playback and narration synchronization, current-snapshot selection, board PNG export state, editing callbacks, the two-page side panel (Script / Setup), controls, and present mode.
- `src/components/PresentationMoves.tsx`: read-only mainline PGN for present mode. Deliberately shows only numbered mainline moves + the current position — no variations, move-quality annotations, timestamps, seek dots, or edit affordances. A passive readout keyed off `reachedEventIndex`, memoized; never the editor `MoveList` with a flag.
- `src/components/Board.tsx`: board rendering, pieces, highlights, arrows, coordinates, capture flash, annotation badges, editing gesture layer. `HlRing` and `BadgeDisc` return elements, not props bags, so a call site cannot restate the geometry and `tsc` enforces it; `lastMoveSquares` and `badgeCenter` are single functions for the same reason — the rule is about the pair, and a ternary per rect leaves it stated only in the difference between two iterations. Carries the resting `grab` cursor (cached per square to keep a `setState` off every `mousemove`, not because the list is expensive: `legalMoves` memoizes on the immutable `GameState`) and reports refused move-starts upward via `onMoveRejected`; it never words the message itself.
- `src/components/MoveList.tsx`: PGN-style move list — numbered mainline rows, inset variation flows, kind-colored seek dots. The Script tab's Moves view: a structured editor with per-event time chips, deletes, and whole-variation delete; auto-follows the playhead only while playback runs. Memoized — the parent re-renders per animation frame, so past/current state derives from `reachedEventIndex`, never from the raw clock.
- `src/components/InsertMenu.tsx`: the script language's way in — a bottom-docked disclosure in the Moves view (`+` trigger, `/` shortcut) that writes the eight argument-free commands at the playhead through `planLineInsert`, and lists the four authored elsewhere (three board gestures, `fen` in Setup) so the menu doubles as the app's only syntax reference. Inline, not a popover: the panel column has room, and an in-flow disclosure can't be clipped by an ancestor's overflow.
- `src/components/Piece.tsx`: piece image mapping.
- `src/components/useRovingTabIndex.ts`: shared roving-tabindex hook (WAI-ARIA toolbar pattern) used by the timeline pin row, the Moves-view list, and the insert menu — one Tab stop per group, arrows walk controls, imperative `tabIndex` so arrow presses never re-render the subtree. Attach it with the `ref` it returns, and nothing else: it observes whatever node it is handed, whenever that node arrives. Controls must render *without* a `tabIndex` prop. A caller that also needs the node passes `opts.mirrorTo`, which the returned `ref` writes into — it is an output, and it sits in `opts` so it cannot be mistaken for the handle to attach.
- `src/components/useLatest.ts`: the render-mirrored ref (`ref.current = value` each render) for callbacks that must read state at call time without taking it as a dep. Shared rather than respelled inline: the two surfaces that need it are the two that re-render every animation frame, so a future hardening has to reach both copies or neither.
- `src/components/SyntaxHint.tsx`: the Text view's one-line syntax reference, rendered from `SYNTAX_GROUPS`. Its own module so the suite can import the element and assert the string a reader actually sees — coverage of the twelve kinds is structural (the groups derive from the catalogue), but the rendering is not: `group.join(' / ')` written as `group[0]` drops `ml` and `reveal` silently.
- `src/lib/animation.ts`: shared playback-clock easing and saturated progress helpers used by Board and mind's-eye visuals.
- `src/lib/playback.ts`: pure playback policies for transport state, authored/clock time ceilings, duration tails, paused event landing, and bounded timeline tick generation.
- `src/lib/chess.ts`: minimal chess state engine, legal move generation, SAN parsing and serialization. `legalMoves` memoizes itself on the immutable `GameState` and returns `readonly Move[]`, so every consumer — the resting cursor, `legalTargets`, `explainNoMoves`, and `parseSAN` on every rebuild — shares one generation per position. The memo is *inside* the primitive, not a wrapper beside it, so no call site can reach an uncached version. `explainNoMoves` names why a square can't start a drag (wrong turn / no legal move), re-deriving legality itself rather than trusting the caller's empty target set.
- `src/lib/commands.ts`: the one catalogue of every event kind the parser accepts — insert body, one-line prose, and the authoring route for the four that need an argument. Both of the app's syntax surfaces read it: the insert menu's rows, and the Text view's one-line hint via `SYNTAX_GROUPS`. Add a kind here, never in a UI file. Pairs come from each entry's `closes` field, never from adjacency in the array. `scripts/test-regressions.mjs` chains it to `markerColors` and asserts the rendered hint names every catalogued command exactly once.
- `src/lib/boardGesture.ts`: pure in-flight gesture state that captures move/arrow/highlight commit callbacks at pointer-down so playback cannot change the position or playhead used at pointer-up.
- `src/lib/boardOrientation.ts`: pure reversible mapping between canonical chess squares and White/Black screen coordinates, shared by every board layer and gesture hit-testing. Symmetric in both directions: `squareViewPosition(sq, o)` and `squareFromBoardView(x, y, o)` both speak square names, so no caller has to bridge through `sqToIdx` itself — one did it twice inside a single expression to fill `boardViewPosition`'s two arguments.
- `src/lib/boardExport.ts`: on-demand 1440×1440 PNG capture of the rendered board plus deterministic time-based filenames; keeps the heavy DOM exporter off the normal playback bundle path until requested. `withTimeout` is the shared ceiling helper, applied once by `App` around the whole export — not around the step that looks riskiest, since the observed hang was in `App`'s frame wait, above this module entirely. Nothing can cancel a rasterize in flight, so a timed-out export is abandoned via an `AbortSignal` that suppresses its download if it settles late.
- `src/lib/mind.ts`: pure mind's-eye domain state and playback-clock visibility curves, shared by the world snapshot walk and Board's renderer.
- `src/lib/world.ts`: pure script/FEN world derivation — immutable board snapshots, runtime script errors, rejected-event tracking, and per-event move-numbering state.
- `src/lib/subtitles.ts`: SRT subtitle parsing and cue validation.
- `src/lib/timeline.ts`: timestamped script parsing. Short syntax is primary: `hl`, direct arrows like `f3->e5`, `cl`, `rs`, `st`, `br`, `ml`, `rp`, `mind`, `reveal`; legacy long commands remain accepted. Also home of the playhead→event-index rule (`lastEventIndexAt`).
- `src/lib/scriptEdit.ts`: gesture-to-script text writer — timestamp formatting, collision stepping, time-sorted line insertion that preserves comments and formatting — plus the pure gesture planners (`planLineInsert`, `planMoveGesture`): branch-aware move policy that returns new script text and landing boundaries, leaving the React commit to `App`.
- `src/lib/tokens.ts`: JS/SVG-facing design tokens mirrored from CSS. `markerForms` sits beside `markerColors` as the other half of "kind is never color alone": both are `Record<MarkerKind, …>`, so TypeScript forces each exhaustive, and the suite asserts the relation between them — two kinds sharing a color must not share a form. Pin shape is data, not a per-kind CSS selector list, so the rule stays checkable. Also home to `markerKindFor`, the rule that a line the snapshot builder rejected keeps its parsed kind but not its parsed color.
- `src/styles.css`: visual system and responsive layout.
- `public/pieces/*.svg`: Staunty chess pieces from Lichess.
