# Architecture

Where things live, and the one contract each module holds its callers to.

Each module's header comment states the same contract next to the code it
constrains; read it before changing the file. How a shape came to be is in git history.

## Code Map

- `src/App.tsx`: React orchestration — draft/import state, the playback clock and transport state, editing callbacks, and present mode. Owns the drafts and the clock, but does not follow the clock frame by frame: it re-renders on state changes and when the playhead crosses an event (`useClockValue`). The export and narration hooks below own their operation state.
- `src/components/BoardColumn.tsx`: the board, the subtitle strip, and the transport (timeline, pins, scrub, speed, SFX). The one subtree that follows the clock every frame (`useClockTime`): it selects the frame's snapshot, drives the move sound, and hands board gestures the time and position they were drawn on.
- `src/components/SidePanel.tsx`: the two-page side panel (Script / Setup) and the errors band. Clock-free: it takes the reached event index, never the time, and its pages and errors band are memoized. Only the insert menu's time label follows the clock, by subscribing itself.
- `src/components/useBoardExport.ts`: board PNG export as one operation at a time. The click snapshots the board synchronously (`snapshotBoard`) and everything awaited works on that copy, so nothing else in the app pauses or locks. Owns the export's status, its 15s ceiling, and the abort on unmount.
- `src/components/useNarration.ts`: the narration track — off-DOM probe, IndexedDB restore, latest-request-wins counter, and the drift-snapped `<audio>` that follows the playback clock ~4×/s through a clock subscription, without re-rendering.
- `src/components/PresentationMoves.tsx`: read-only mainline PGN for present mode. Deliberately shows only numbered mainline moves + the current position — no variations, move-quality annotations, timestamps, seek dots, or edit affordances. A passive readout keyed off `reachedEventIndex`, memoized; never the editor `MoveList` with a flag. `buildMainline` takes "on the main line" from `snapshots[i].branchDepth`.
- `src/components/Board.tsx`: board rendering, pieces, highlights, arrows, coordinates, capture flash, annotation badges, editing gesture layer. `HlRing`, `BadgeDisc` and `LastMoveRect` return elements, not props bags, so a call site cannot restate the geometry and `tsc` enforces it; `lastMoveSquares` and `badgeCenter` are single functions for the same reason — the rule is about the pair, and a ternary per rect leaves it stated only in the difference between two iterations. Takes the frame's `chessState` and asks `chess.ts` for legal targets itself. Carries the resting `grab` cursor (cached per square to keep a `setState` off every `mousemove`, not because the list is expensive: `legalMoves` memoizes on the immutable `GameState`; the cache resets when `chessState` changes identity) and reports refused move-starts upward via `onMoveRejected`; it never words the message itself.
- `src/components/MoveList.tsx`: the Script tab's Moves view — numbered mainline rows, inset variation flows, kind-colored seek dots, per-event time chips, deletes, and whole-variation delete. Renders the outline from `moveOutline.ts` and derives no structure of its own. Auto-follows the playhead only while playback runs. Past/current state derives from `reachedEventIndex`, never from the raw clock, so playback re-renders it only at event crossings.
- `src/components/InsertMenu.tsx`: the script language's way in — a bottom-docked disclosure in the Moves view (`+` trigger, `/` shortcut — both its own state, so mounting is the gate and leaving the view closes it) that writes the eight argument-free commands at the playhead through `planLineInsert`, and lists the five authored elsewhere (three board gestures, `fen` in Setup, `ask` in Text) so the menu doubles as the app's only syntax reference. Inline, not a popover: the panel column has room, and an in-flow disclosure can't be clipped by an ancestor's overflow.
- `src/components/AskCard.tsx`: the `ask` question card shown in the subtitle strip — question text beside a countdown ring and digit, both derived from `time - ask.t`. Which card is live comes from `activeAskAt` in `timeline.ts`, not from world snapshots.
- `src/components/Piece.tsx`: piece image mapping.
- `src/components/useRovingTabIndex.ts`: shared roving-tabindex hook (WAI-ARIA toolbar pattern) used by the timeline pin row, the Moves-view list, and the insert menu — one Tab stop per group, arrows walk controls, imperative `tabIndex` so arrow presses never re-render the subtree. Attach it with the `ref` it returns, and nothing else: it observes whatever node it is handed, whenever that node arrives. Controls must render *without* a `tabIndex` prop. A caller that also needs the node passes `opts.mirrorTo`, which the returned `ref` writes into — it is an output, and it sits in `opts` so it cannot be mistaken for the handle to attach.
- `src/components/useLatest.ts`: the render-mirrored ref (`ref.current = value` each render) for callbacks that must read state at call time without taking it as a dep.
- `src/components/SyntaxHint.tsx`: the Text view's one-line syntax reference, rendered from `SYNTAX_GROUPS`. Its own module so the suite can import the element and assert the string a reader actually sees — coverage of the thirteen kinds is structural (the groups derive from the catalogue), but the rendering is not: `group.join(' / ')` written as `group[0]` drops `ml` and `reveal` silently.
- `src/lib/scrollEventIntoView.ts`: the one scroll rule the two move lists share — locate the row by its `data-evi` attribute and nudge the container's own `scrollTop` the minimum needed, never the page. `MoveList` and `PresentationMoves` both call it; *when* to call it (playback state, hover-pause) stays with the caller.
- `src/lib/clock.ts`: the playback clock — the one current time, held in a small store outside React state. `useClockTime` re-renders its caller every tick; `useClockValue` only when a derived primitive (an event index, a label) changes. Timed code reads the clock; nothing keeps a second copy of the time.
- `src/lib/animation.ts`: shared playback-clock easing and saturated progress helpers used by Board and mind's-eye visuals.
- `src/lib/playback.ts`: pure playback policies for authored/clock time ceilings, duration tails, paused event landing, and bounded timeline tick generation.
- `src/lib/chess.ts`: the sole `chess.js` adapter. `GameState` is a frozen canonical-FEN value with move-number readouts; no mutable library instance or library type crosses into the timeline or React. The adapter maps the library's a8-first board and algebraic squares into Gambit's rank-1-first board and `[file, rank]` moves, owns quality-suffix parsing and edit-rejection prose, and answers the board gesture's questions — which squares a piece can reach (`legalTargets`), which legal moves connect two squares (`movesBetween`), whether two moves name the same squares (`sameMoveSquares`) — so no caller has to know that a `Move` carries `[file, rank]` tuples. Rejects the FEN positions chess.js loads on trust (see [script-language.md](script-language.md)). Memoizes two pure results: `legalMoves` by `GameState` identity, and `playSAN` — the snapshot walk's one engine load per move — by `fen|SAN` value in a bounded LRU, so a rebuild after a tail edit replays the unchanged prefix from cache and gets back the same `GameState` objects.
- `src/lib/commands.ts`: the one catalogue of every event kind the script language has — canonical token, the words that select it (token and long alias), its argument parser, one-line prose, and the authoring route for the five that need an argument. The parser dispatches on it (`COMMAND_PARSERS`), and both syntax surfaces read it: the insert menu's rows, and the Text view's one-line hint via `SYNTAX_GROUPS`. A new kind's syntax is one entry here plus its `EventFields` variant — never a UI file or a parser branch. Arrows and SAN are the two forms recognised by shape rather than by word (`parseArrow`, then SAN). Pairs come from each entry's `closes` field, never from adjacency in the array. `test/commands.test.mjs` chains it to `markerColors`, to the parser, and to the rendered hint.
- `src/lib/boardGesture.ts`: pure in-flight gesture state that captures move/arrow/highlight commit callbacks at pointer-down so playback cannot change the position or playhead used at pointer-up.
- `src/lib/boardOrientation.ts`: pure reversible mapping between canonical chess squares and White/Black screen coordinates, shared by every board layer and gesture hit-testing. Symmetric in both directions: `squareViewPosition(sq, o)` and `squareFromBoardView(x, y, o)` both speak square names, so no caller has to bridge through `sqToIdx` itself.
- `src/lib/boardExport.ts`: 1440×1440 PNG capture of the rendered board. `snapshotBoard` clones the board, drops the gesture preview (`BOARD_GESTURE_CLASS`), and mounts the clone off-screen; `downloadBoardPng` rasterizes a snapshot and delivers it under a time-based filename. The DOM exporter loads on demand, off the playback bundle path. `withTimeout` is the ceiling helper `useBoardExport` applies once around the whole export; a timed-out export is abandoned through an `AbortSignal` that suppresses its late download.
- `src/lib/narrationStore.ts`: the narration track's draft store, IndexedDB rather than localStorage because audio does not fit a few megabytes of UTF-16. Fails soft the way `saveDraft` does — a denied store costs the reload, never the session.
- `src/lib/moveSound.ts`: the piece click. Derives from the frame's `lastMove` rather than from the event that produced it, so one rule covers playback, replay steps, scrub landings, and a gesture's own paused landing — and nothing has to tell it a move happened. The key is a value (`squares@t`), not the snapshot's object identity: `buildWorld` re-derives every snapshot on each keystroke, and identity comparison would click at all of them. The ref it keeps is a "have I said this one" latch, not board state.
- `src/lib/renderMode.ts`: the `?render` flag and `window.gambitRender`, the handle `scripts/render-video.mjs` drives to grab frames offline. It sets the clock and counts move clicks through the sound sink; it never writes board state. See [playback.md](playback.md#offline-video-render).
- `src/lib/mind.ts`: pure mind's-eye domain state and playback-clock visibility curves, shared by the world snapshot walk and Board's renderer.
- `src/lib/moveOutline.ts`: the Moves view's structure as pure data — mainline rows, variation flows, dividers, errors — built once from the events and the snapshots' `chessState` and `branchDepth`. Every number in it is an index into `events`.
- `src/lib/world.ts`: pure script/FEN world derivation — immutable board snapshots (`snapshots[i]` is the world before event `i`, and also numbers that event's move row), runtime script errors, and rejected-event tracking. `branchDepth` on each snapshot is the one count of `br`/`ml` nesting; every consumer reads it rather than re-counting.
- `src/lib/subtitles.ts`: SRT subtitle parsing and cue validation.
- `src/lib/timeline.ts`: timestamped script parsing — the `[time] body` line shape, timestamps, limits, and dispatch to the command catalogue; a line with no command word is an arrow or else SAN. Also home of the event types, the playhead→event-index rule (`lastEventIndexAt`), and the live question card rule built on it (`activeAskAt`).
- `src/lib/scriptEdit.ts`: gesture-to-script text writer — timestamp formatting, collision stepping, time-sorted line insertion that preserves comments and formatting — plus the pure gesture planners (`planLineInsert`, `planMoveGesture`): branch-aware move policy that returns new script text and landing boundaries, leaving the React commit to `App`.
- `src/lib/tokens.ts`: JS/SVG-facing design tokens mirrored from CSS. `markerForms` sits beside `markerColors` as the other half of "kind is never color alone": both are `Record<MarkerKind, …>`, so TypeScript forces each exhaustive, and the suite asserts the relation between them — two kinds sharing a color must not share a form. Pin shape is data, not a per-kind CSS selector list, so the rule stays checkable. Also home to `markerKindFor`, the rule that a line the snapshot builder rejected keeps its parsed kind but not its parsed color.
- `src/lib/defaults.ts`: the first-run script and subtitle text, read only as `App`'s draft fallback. A worked example, not a syntax reference: its header comment points at the two surfaces derived from `commands.ts` rather than restating the catalogue.
- `src/styles.css`: visual system and responsive layout.
- `test/*.test.mjs`: the regression suite, one file per module ([testing.md](testing.md)).
- `public/pieces/*.svg`: Staunty chess pieces from Lichess.
- `public/sounds/move.mp3`: the piece-click sample, served from the app's own origin like the pieces and fonts.
